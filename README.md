# Telit_Framework_practice_2026
This framework is built based on Interview Question or Assignment of Telit 

**Notes:**
* *Main Method:*
  * "Main" is going to be the class which is going have the main method inside. Technically it's going to be the runner class. Runner class means execution is supposed to start.

* *Instance variables* 
  * are always marked with "Private" visibility.
  * are created in the heap memory.
  * are always initialzed with default value.
  * The job of the constructor is to initialize the instance variable.
